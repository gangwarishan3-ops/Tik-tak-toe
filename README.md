# 🎮 Tic Tac Toe - Two Player Game

A modern, feature-rich Tic Tac Toe game for two human players with score tracking and smooth animations.

## 🚀 Quick Start

### Windows
**Option 1: Double-click the run script**
```
run.bat
```

**Option 2: Open directly in browser**
- Double-click `index.html` file

**Option 3: Run via command line**
```powershell
start index.html
```

### Mac/Linux
```bash
open index.html
# or
python -m http.server 8000
# Then open http://localhost:8000 in browser
```

## ✨ Features

### Game Mode
- **2-Player Mode**: Play with a friend on the same device

### Advanced Features
- ✅ **Score Tracking**: Win/Loss/Draw counter for both players
- 📊 **Game Status Display**: Real-time turn indicator
- 🎨 **Modern UI**: Gradient design with smooth animations
- 💾 **Persistent Score**: Scores saved using localStorage
- 📱 **Responsive Design**: Works on desktop, tablet, and mobile
- 🎮 **Simple Controls**: Click to play, no complexity

## 🎯 How to Play

1. **Player 1** plays as **O** (Green color)
2. **Player 2** plays as **X** (Orange/Yellow color)
3. Players take turns clicking empty squares
4. First to get three in a row (horizontally, vertically, or diagonally) wins!
5. Click "New Game" to reset the board and start again
6. Click "Clear Score" to reset all statistics
